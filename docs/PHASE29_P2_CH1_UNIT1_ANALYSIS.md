## Author-method
핵심은 to부정사의 세부 용법을 외우기 전에 빈칸이 본동사 자리인지 준동사 자리인지 먼저 판정하는 것이다.

1. 문장에 본동사가 이미 있는지 확인
2. 없으면 본동사 자리 → 시제·수일치를 갖춘 동사
3. 있으면 준동사 자리 가능
4. 준동사 자리에서 명사·형용사·부사 역할을 확인
5. 해당 자리에서 to-V를 선택

앱 순서:
`Cold Attempt → 본동사 유무 → 본동사/준동사 자리 → 문장 역할 → 최종 형태 → 5초 Rule → 재도전`
