# Phase 3 - 반응형 학습 UI 와이어프레임

## 목표

iPad, Galaxy Tab, PC에서 같은 학습 흐름을 유지하면서 영어 문장과 선택지를 크게 읽을 수 있도록 한다.

## 고정 원칙

- 본문 최대 폭: 약 980px
- 상단 헤더 최대 폭: 약 1080px
- 영어 문제 글자: 약 25-38px 범위에서 반응형
- 선택 버튼 높이: 최소 60-64px
- 단어 탭 버튼: 최소 52px
- 태블릿 이하에서는 선택지 1열
- PC에서는 2개 선택지를 2열로 표시 가능
- 한 화면 한 과제 원칙
- 하단 주요 버튼은 sticky 처리하되 본문을 가리지 않음
- safe-area 대응
- reduced-motion 환경 대응

## Phase 3 데모 흐름

1. Cold Attempt
2. 본동사 탭
3. 절 연결어 탭
4. 본동사/준동사 자리 판단
5. 5초 Rule 제시
6. 원문 재도전
7. 상태 표시

## 콘텐츠 정책

현재 저장소가 Public이므로 Phase 3 UI 검증에는 교재 원문 대신 저자식 규칙을 검증할 수 있는 별도 데모 문장을 사용한다. 실제 교재 데이터 연결은 콘텐츠 공개 범위가 정리된 이후 진행한다.
