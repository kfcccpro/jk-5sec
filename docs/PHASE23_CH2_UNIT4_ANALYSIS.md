## 1. 저자식 핵심

교재는 감각동사 다섯 개를 묶는다.

- feel
- look
- smell
- sound
- taste

이 동사들이 `~하게 느껴지다 / 보이다 / 냄새나다 / 들리다 / 맛이 나다`의 의미로 쓰이면 2형식 연결동사이고, 뒤에는 주어의 상태를 설명하는 주격보어가 필요하다.

따라서 출제 포인트는 **형용사 vs 부사**다. 감각동사 뒤가 주격보어 자리라면 `-ly` 부사가 아니라 형용사를 고른다.

## 2. 5초 판단 순서

`감각동사 확인 → 2형식 연결동사 여부 → 주격보어 자리 확인 → 형용사 선택`

### A. 감각동사 확인

feel / look / smell / sound / taste 중 하나인지 먼저 확인한다.

### B. 2형식 판정

동사가 주어의 상태·인상·감각을 이어 주면 2형식이다. 이때 뒤 성분은 동작 방식을 꾸미는 부사가 아니다.

### C. 주격보어

빈칸이 주어를 설명하면 주격보어 자리다.

### D. 형용사 선택

주격보어에는 형용사를 사용한다. 문제에 형용사와 `-ly` 부사가 함께 제시되면 형용사를 고른다.

## 5. Derived practice

교재 문장을 복제하지 않고 감각동사별 파생문항을 1개씩 둔다.

1. feel — soft / softly
2. look — quiet / quietly
3. smell — fresh / freshly
4. sound — reasonable / reasonably
5. taste — mild / mildly
