## Author-method
이 UNIT은 명사가 동사 뒤에 직접 목적어로 붙는지, 또는 전치사를 거쳐 연결되는지를 먼저 본다.

`핵심 동사 → 명사 연결 방식 → 자동사/타동사 → 전치사 필요 여부`

대표 타동사군은 answer, approach, discuss, enter, marry, reach, resemble처럼 목적어 앞 불필요한 전치사를 쓰지 않는 유형이다. 자동사는 목적어를 직접 취하지 않아 필요한 경우 전치사와 연결한다.
