# Phase 4 - 실제 앱 골격

## 구현 범위

- 학생 PIN: 8081
- 관리자 PIN: 2007
- 회원가입/이메일 로그인 없음
- 학생 홈
- 관리자 최소 대시보드
- UNIT 1 학습 진입
- 학습 결과 localStorage 저장
- 최초 정답률, 교정 성공, 미해결, 최근 상태 표시
- iPad/Galaxy Tab/PC 반응형 UI

## 현재 저장 방식

현재 Phase 4는 백엔드 없이 브라우저 localStorage만 사용한다.
따라서 같은 기기/브라우저에서는 기록이 유지되지만 기기 간 동기화는 아직 지원하지 않는다.

이 프로젝트의 우선순위는 단순성이다. 실제 다기기 동기화가 필요하다고 판단되는 시점에만 Firestore 익명 인증 등 최소 구성을 별도 Phase에서 추가한다.

## 화면 설계 기준

- 태블릿을 기본 화면으로 설계
- 콘텐츠 최대 폭 980~1120px
- 영어 문제 글자 25~38px
- 주요 선택 버튼 60px 이상
- safe-area, 100dvh 대응
- 세로 태블릿은 기본 1열
- 넓은 PC에서는 관리자/홈 정보만 2열
- 학습 문제는 PC에서도 한 화면 한 과제 원칙 유지
- 작은 가로 높이 환경에서는 카드 최소 높이를 해제해 스크롤 부담을 줄임
