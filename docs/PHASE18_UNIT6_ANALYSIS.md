## 1. 저자식 핵심

UNIT 6의 핵심은 `be + p.p.` 뒤에 명사가 있다고 해서 수동태를 배제하지 않는 것이다.

### 4형식 수동태

교재가 제시하는 대표 동사군은 `give, lend, send, pay, offer, ask, show, teach, tell`이다.

능동태에서 `동사 + 간접목적어 + 직접목적어`였던 구조가 수동태가 되면 한 목적어가 주어로 올라가고 다른 목적어가 뒤에 남을 수 있다.

따라서 `be + p.p. + 명사`의 명사는 여전히 **목적어**일 수 있다.

### 5형식 수동태

교재가 제시하는 대표 동사군은 `consider, call, name, elect, appoint`이다.

능동태의 `목적어 + 목적격보어`에서 목적어가 수동태의 주어로 올라가면 원래 목적격보어는 주어를 설명하는 **주격보어** 역할로 남는다.

따라서 `be + p.p. + 명사`의 명사는 목적어가 아니라 **보어**일 수 있다.

## 2. 앱용 5초 판단 순서

`원래 4·5형식 확인 → p.p. 뒤 남은 명사 역할 확인 → 수동태 성립 판정`

1. 대상 동사가 4형식 두 목적어 구조인지 5형식 목적어+목적격보어 구조인지 판단한다.
2. 수동태 뒤 명사가 4형식의 남은 직접목적어인지, 5형식에서 주어를 설명하는 보어인지 판단한다.
3. 명사가 남았다는 이유만으로 수동태를 제거하지 않는다.

## 4. Derived practice

5개 파생문항은 교재 원문을 복사하지 않고 다음을 전이한다.

1. give — 4형식 수동태 + 남은 직접목적어
2. show — 4형식 수동태 + 남은 직접목적어
3. teach — 4형식 수동태 + 남은 직접목적어
4. consider — 5형식 수동태 + 보어
5. appoint — 5형식 수동태 + 보어
