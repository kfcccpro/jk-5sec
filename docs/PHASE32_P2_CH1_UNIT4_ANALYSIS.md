## Decision loop
`본동사 확인 → 본동사와 to-V 사이 목적어 O 확인 → to-V의 목적격 보어 역할 → 최종 to-V`

## Key contrast
- UNIT 2: `V + to-V` — to-V가 목적어
- UNIT 4: `V + O + to-V` — to-V가 목적격 보어
- 사역/지각동사의 원형부정사 보어와도 구별한다.
